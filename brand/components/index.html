The Cleo component palette

Every building block the Cleo dashboard needs, from tokens to full screens, drawn in the Cleo brand. Service advisors live in this product all day, so the system favours calm surfaces, dense but readable data, and clear signals for anything that needs a human.

Foundations

The tokens every component is built from. Nothing below uses a raw value: colour, type, space, radius, elevation and motion all come from here.

Colour

Brand ramps run light to dark: four tints, the base (outlined), three shades. Ink is the primary action colour on the dashboard; Cleo Blue is the accent for links, focus, selection and Cleo's own voice.

Type scale

Geist throughout, Geist Mono for codes, VINs and timestamps. Headings track -2%, body text +0.5%. The dashboard rarely goes above Heading 5.

Motion & the living mark

One motion language, built on draw-on: a one-shot reveal for loads, and a perpetual trace for anything Cleo is working on. The mark never shrinks, and the line keeps a minimum weight so it reads at 16px. All mark motion stops when the viewer prefers reduced motion.

Draw-onThe outline traces in, the colour fills, and the mark settles. App and page load.
TracingA short stroke runs around the outline without end. No fill, no turn. Cleo Blue on light surfaces, white in dark mode and on blue, mono on coloured fills. Loading, saving, thinking, live calls.

Mark variants

Full colour is the default. White sits on Cleo Blue fills. Mono takes the text colour of wherever it sits, so the mark never clashes with a green, amber or red context.
